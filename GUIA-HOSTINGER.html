Tu tienda.
Lista para instalar.

Paquete PHP + MySQL para Hostinger. Incluye 300 productos, cuentas de clientes, carrito, pedidos, inventario y administración.

Antes de vender: conecta tus pagos y correo, confirma precios y stock, y completa tus políticas. El paquete se instala en demostración, sin cobros y con stock en cero.

1. Prepara tu hosting

Necesitas un plan de Hostinger con PHP y MySQL. Activa PHP 8.2 o superior, el certificado SSL y crea una base MySQL con su usuario. No requiere Node.js ni Docker.

2. Sube los archivos

Descomprime el ZIP. Pon los archivos de public_html en la carpeta pública de tu dominio. La carpeta private debe quedar a su lado, fuera de ella.

carpeta-del-dominio/
  private/
    config.php
    catalog.json
    ...
  public_html/
    index.html
    api.php
    install.php
    assets/
    ...

3. Conecta la base de datos

Copia private/config.example.php como private/config.php. Escribe tu dominio HTTPS y los datos de MySQL de hPanel. Habilita las extensiones PHP PDO MySQL, cURL, OpenSSL, mbstring y fileinfo.

4. Crea tu cuenta de administrador

Abre https://tudominio.com/install.php. La clave del instalador está en private/setup.key. Elige tu correo y una contraseña nueva. Las tablas y el catálogo se crean automáticamente.

Después de instalar, elimina public_html/install.php y private/setup.key del servidor. Entra a “Mi cuenta” para acceder a Administración.

5. Configura y prueba tus ventas

  1. Productos: confirma modelo, variante, precio y existencias reales. Marca cada artículo como verificado para venderlo.
  2. Configuración: completa contacto, razón social, domicilio, tarifas de envío y tus políticas.
  3. Pagos y correo: introduce tus claves de Mercado Pago, Stripe y SMTP en el archivo privado. Las transferencias se configuran desde Administración.
  4. Prueba: realiza una compra de prueba y comprueba la confirmación del pago, el pedido, el correo y el inventario. Después desactiva el modo de demostración.

Lo que ya se verificó

Se aprobaron 14 grupos de pruebas de registro, permisos, carrito, stock, pedidos y recuperación. Se probó el recorrido de compra en navegador y la vista móvil. El enlace superior “Laptops” muestra 12 modelos.

Lo que debes conectar

No se ha publicado en tu cuenta de Hostinger ni se han hecho cobros reales. Los pagos, SMTP y MySQL deben validarse en tu servidor. Las guías, facturas, reembolsos y licencias digitales requieren gestión adicional del negocio; no están automatizados.

Instrucciones completas: abre README.md dentro del paquete. También incluye VALIDACION.md, el esquema database.sql y CATALOGO-FUENTES.csv con las referencias oficiales de los productos.
